# Wedding Landing Page

Landing page slubny inspirowany zaproszeniem, retro plakatami filmowymi i specyfikacja z `specs/WEDDING_LANDING_EXTENDED_SPEC_FOR_CODEX.md`.

## Uruchomienie

```bash
npm run dev
```

Strona bedzie dostepna pod adresem:

```txt
http://localhost:5173
```

Projekt jest statyczny i nie wymaga instalowania zaleznosci.

## Struktura

```txt
assets/   grafiki i zaproszenie PDF
specs/    specyfikacja produktu
index.html
styles.css
script.js
```
